# youtin

An intentional, privacy-first social experience featuring a refined liquid-glass aesthetic, custom color & glass themes, Instagram-proportional edge-to-edge feeds, seamless vertical Mini reels, and end-to-end private messaging.

---

## ✨ Key Features

- **Splash Screen Branding**: Liquid-glass iridescent emblem and signature cursive typography presented upon app launch.
- **Edge-to-Edge Feed**: Clean borderless photo and carousel posts spanning 100% width with generous detail, custom like animations, bookmarks, and thread commentary.
- **Mini Vertical Reels**: TikTok & Instagram Reels-style smooth vertical swipe/scroll navigation with double-tap heart animations, sound toggling, and comment drawers.
- **Privacy & Account Sovereignty**:
  - **Private Account vs. Public Creator Mode**: Configured seamlessly inside Settings.
  - **Circles & Close Friends Filters**: Granular audience rings without invasive tracking or ad algorithms.
  - **Zero Ads**: Transparent, human-centric design.
- **Theme Studio**: Dynamic liquid-glass blur customization, specular lighting effects, and personal accent color pickers (Cyan, Violet, Emerald, Rose, Amber, Gold, etc.).
- **Encrypted Messaging**: Direct conversations, connection request management, and ephemeral story circles.

## 🚀 Getting Started Locally

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- `npm` or `bun`

### Installation

1. **Clone or export the repository**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/youtin.git
   cd youtin
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

## 📦 Publishing to GitHub from Google AI Studio

You have two simple ways to publish this project to GitHub:

### Option 1: Built-in 1-Click Export (Fastest & Recommended)
1. In the Google AI Studio build window, click the **Settings / Menu icon** (top right corner).
2. Select **Export to GitHub** (or **Download ZIP**).
3. Connect your GitHub account and choose either a new repository or existing repository.
4. AI Studio will automatically push all source files and commit history directly to your GitHub repository!

### Option 2: Push via Git CLI
If you downloaded the project as a ZIP file or have a local clone:
```bash
git init
git add .
git commit -m "Initial commit of youtin social app"
git branch -M main
git remote add origin https://github.com/<YOUR-USERNAME>/youtin.git
git push -u origin main
```
